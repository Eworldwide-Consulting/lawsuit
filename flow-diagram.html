🟡 Medium Security 2FA "Trust this device for 30 days" checkbox has no backend implementation — state is captured in TwoFactor.jsx but never sent to or processed by the server client/src/pages/auth/TwoFactor.jsx:10 Implement device trust via a device fingerprint cookie + backend whitelist, or remove the UI element
🟡 Medium Security "Use backup code" button is a UI placeholder — present in TwoFactor.jsx but has no handler or route client/src/pages/auth/TwoFactor.jsx Implement TOTP backup codes (generate + store hashed at setup, verify on use) or remove button
🟡 Medium Auth "Remember Me" checkbox in Login stores nothing — state is tracked but never used to set different token expiry or session persistence client/src/pages/auth/Login.jsx:15 Pass rememberMe flag to backend; use long-lived token (30d) vs short-lived (1d) based on flag
